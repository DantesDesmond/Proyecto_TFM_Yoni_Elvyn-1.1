# Objetivos base del proyecto

## Objetivo general
Diseñar e implementar una aplicación local en Streamlit para la detección automática de toxicidad y discurso de odio en comentarios de YouTube en español mediante técnicas de procesamiento de lenguaje natural.

## Objetivos específicos
1. Revisar la literatura reciente y definir un protocolo experimental con Macro-F1 como métrica principal.
2. Construir un pipeline local de ingesta y preprocesamiento de comentarios de YouTube.
3. Entrenar y evaluar baselines clásicos y al menos un modelo transformer en español.
4. Integrar el modelo final en una aplicación local con visualización de resultados.
5. Documentar resultados, errores y evidencias para el TFM.
